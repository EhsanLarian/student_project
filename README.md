# Student Grades Management 🎓

A simple Python console application to calculate student grades and determine their status.

## Project Structure
- `main.py` – Main script to handle user input and call functions.
- `Student/grades.py` – Functions to calculate average, maximum, and minimum grades.
- `Student/status.py` – Function to determine pass/fail status based on the average.

## How to Run
```bash
python main.py
